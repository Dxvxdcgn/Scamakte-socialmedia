Microsoft 365. Klartext. Ohne Admin-Nebel.

Teams, Admin-Center und Co. verständlich erklärt.

TenantTalk ist ein deutschsprachiges Videoformat über Microsoft 365, Microsoft Teams und Administration von David Baker. Die zugehörige private Publishing-Anwendung („TenantTalk Publisher“) veröffentlicht ausschließlich eigene Produktionen auf ausdrücklich autorisierten Social-Media-Konten des Betreibers.

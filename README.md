# Scam-Akte Social Publishing

Dieses öffentliche Repository enthält ausschließlich die statischen Informations- und Rechteseiten der redaktionellen Social-Publishing-Anwendung von Scam-Akte.

## Veröffentlichung mit GitHub Pages

1. In GitHub `Settings → Pages` öffnen.
2. Unter `Build and deployment` die Quelle `Deploy from a branch` wählen.
3. Branch `main` und Ordner `/docs` auswählen und speichern.
4. Nach dem ersten erfolgreichen Build die angezeigte Website öffnen.

Die Seite verwendet keine Cookies, kein Tracking und keine extern geladenen Schriftarten. Zugangsdaten, OAuth-Tokens und Plattform-Secrets gehören niemals in dieses Repository.

Die Rechtstexte sind ein technischer Entwurf und ersetzen keine Rechtsberatung.
